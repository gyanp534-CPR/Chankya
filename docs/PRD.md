# Product Requirements (PRD)

## Summary
Chankya is a UPSC preparation platform focused on PYQ intelligence, adaptive practice, and mentorship-driven feedback.

## Goals
- Deliver clean, structured PYQ practice flows.
- Provide adaptive guidance with explainable next actions.
- Improve retention via daily focus prompts.

## Non‑Goals
- Full AI explanation generation in v1.
- Spaced repetition engine beyond basic decay.
- Mobile-first feature parity before core web stability.

## Success Metrics
- Daily active usage of “Today’s Focus”.
- Completion rate of focused practice sets.
- Improvement trend after targeted practice.

## Personas
- UPSC beginner (needs structure).
- UPSC intermediate (needs targeted practice).
- UPSC advanced (needs challenge + weak area correction).

## Scope (v1)
- Practice session flow.
- Post‑attempt mentor feedback.
- Learning path / daily focus.
- Explanation snippets aligned to trap types.

## Out of Scope (v1)
- Full concept graph navigation UI.
- AI free‑form tutoring.
- Mobile client feature parity.
