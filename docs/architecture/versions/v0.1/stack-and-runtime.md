# Stack and Runtime - v0.1

## Backend
- Node.js LTS
- Fastify preferred over Express for throughput and plugin ergonomics
- Prisma ORM with PostgreSQL
- JWT auth with access + refresh token design planned in v0.2
- Redis postponed until performance hotspots are proven

## Frontend
- Web: Next.js 15, App Router
- Mobile: Expo React Native
- Shared API contracts across clients

## Data
- PostgreSQL as source of truth
- No Firebase dependency
- AI framework lock-in avoided

## Principles
- Portability first
- Cost-awareness from day one
- Independent backend that can move cloud providers
