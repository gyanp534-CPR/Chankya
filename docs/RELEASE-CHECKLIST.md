# Release Checklist

## Before Release
- PR approved and merged to `main`.
- Backend migrations reviewed.
- Environment variables verified.
- Vercel preview validated (frontend).
- API endpoints verified (backend).

## Deploy
- Production deploy triggered by merge to `main`.
- Confirm Vercel deployment is healthy.
- Confirm backend health checks.

## After Release
- Monitor logs for new errors.
- Validate Today’s Focus and practice flow.
- Update CHANGELOG if needed.
