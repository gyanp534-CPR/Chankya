ML ROADMAP (LIGHTWEIGHT)

Goal:
- Parser “learns” from corrected questions.
- Current parser is rule-based; needs training loop.

Stage 1: Build Training Dataset
- Use clean 100-question JSON per year as ground truth.
- Pair OCR output vs ground truth.
- Generate diff dataset.

Stage 2: Lightweight ML Model
- Line-level classifier: question / option / noise.
- Small model: MiniLM or DistilBERT.
- Few thousand labeled lines enough.

Stage 3: Integrate into Pipeline
OCR text → ML line classifier → segmenter → normalized JSON.

Stage 4: Expand
- CSAT-specific model (passage-aware).
- Answer prediction.
- Topic tagging automation.
