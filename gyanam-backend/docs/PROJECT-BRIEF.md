# Project Brief

Gyanam is an AI-assisted UPSC learning platform that converts previous year questions into structured knowledge, practice, and analytics.

## Scope (Current)
- UPSC Prelims
- GS Paper 1 and CSAT Paper 2

## Objectives
- Concept-level tagging for adaptive learning
- Reliable answer-key reconciliation
- Analytics-ready concept graph

## Current Status
- PYQ extraction, normalization, and validation in place
- Tagging schema v1.2 implemented with CORE/ADVANCED split
- Derived concept graph outputs available

## Next Milestone
Produce the first fully answer-resolved and ingestion-ready PYQ dataset.
